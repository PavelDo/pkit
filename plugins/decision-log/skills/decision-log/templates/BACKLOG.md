# Backlog — ideas parked, not scheduled

Staging ground for ideas that are recorded but deliberately not being built.
An idea here costs one entry; building it costs a decision. An entry
graduates by becoming a spec, an issue, or a work block in an epic — link
the destination when it does. Append entries; when one graduates or dies,
mark it rather than deleting it.

Entry shape:

### <idea name>
<2-4 lines: what it is, what it builds on, what would trigger building it.>
Source: <who, where, date>. Graduates to: <spec / issue / epic block / dead — with link>.
